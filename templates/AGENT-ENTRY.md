# 本机工具和目录管理

涉及本机工具选择、开发环境、安装、升级、卸载、配置或目录整理时，先读取：

- `{{MACHINE_DIR}}/POLICY.md`：长期原则。
- `{{MACHINE_DIR}}/TOOLS.md`：工具索引；需要详情时读取同目录 tools.json。

优先复用已有工具和符合要求的依赖。相关变更完成后更新工具登记，运行 refresh-inventory.py 刷新索引，并记录变更。

分别判断已安装、已配置、已验证和当前会话可调用。不能从索引推断 MCP 已连接或获得额外操作权限。读取失败时说明限制，不据此判定工具不存在。

目录整理逐项迁移和验收，不直接批量搬动已有运行环境。当前用户明确要求及适用的上级指令优先。
